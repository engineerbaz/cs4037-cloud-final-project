# Pre-Submission Checklist

Go through every line before you paste the link into Google Classroom.

## Content
- [ ] Every requirement in the brief is ticked and has evidence
- [ ] Architecture diagram is in `submission/diagrams/` and shown in the report
- [ ] The Defend It answer is written
- [ ] Testing results include real measurements
- [ ] At least one real problem and its fix is described
- [ ] Cost section is complete
- [ ] Cleanup proof is included

## Group work
- [ ] Every member has commits under their own GitHub account
- [ ] The team table and individual contributions table are filled in
- [ ] Each member can explain the whole project, not only their own part

## Security
- [ ] No access keys, secret keys, `.pem` files, passwords, or `.env` files in the repo or its history
- [ ] AWS account ID and email addresses are blurred in screenshots
- [ ] All AWS resources are deleted

## Repository
- [ ] Repo is private and the instructor is added as a collaborator
- [ ] The repo link opens correctly when pasted in a private browser window while logged in as the instructor
- [ ] The latest work is merged into `main`
